Fail2Ban_AbuseIPDB

Report every ban, lose none of them

Asynchronous fail2ban to AbuseIPDB reporter: every ban is queued in SQLite and submitted with evidence on a schedule, surviving API rate limits, reboots and downtime.

What it does

  • Durable local queue: nothing is lost on restart
  • Rich reports with the evidence AbuseIPDB asks for
  • systemd units, cron mode and SHA-256 self-update

Built with

Python, Shell
